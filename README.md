# راهنمای Git و GitHub برای دانشجویان

این مخزن یک مستند آموزشی جامع و کاربردی برای دانشجویانی است که قصد دارند کار با سیستم کنترل نسخه **Git** و پلتفرم **GitHub** را از سطح مبتدی تا انجام پروژه‌های گروهی به صورت عملی یاد بگیرند.

## اهداف این راهنما
- آشنایی با مفاهیم پایه کنترل نسخه و دستورات ضروری Git
- یادگیری کار با شاخه‌ها (Branching) برای توسعه موازی و امن
- درک فرآیند ادغام تغییرات (Merging) و روش حل دستی تعارض‌ها (Merge Conflict)
- تسلط بر جریان کار تیمی در GitHub شامل Issue، Pull Request و Code Review

## ساختار مستندات مخزن
- [basic-commands.md](./basic-commands.md): نصب، راه‌اندازی مخزن و دستورات پایه Git
- [branching.md](./branching.md): مدیریت شاخه‌ها و استانداردهای توسعه موازی
- [merging.md](./merging.md): ادغام شاخه‌ها و حل دستی Merge Conflict
- [collaboration.md](./collaboration.md): کار تیمی در GitHub، مدیریت Issue و Pull Request
